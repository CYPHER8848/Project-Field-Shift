# Field Shift — visual style guide

Editorial direction: a warm field journal rather than a conventional dashboard.

| Role | Hex |
|---|---|
| Field green | #24372B |
| Sage | #788064 |
| Warm paper | #F4F1E8 |
| Chalk | #FFFDF7 |
| Earth | #9A815B |
| Terracotta | #B65D3D |
| Harvest gold | #E8B95C |
| Pale leaf | #DCE5C9 |

Typography: Fraunces for story headings; DM Sans for interface, labels, data and body copy.
Layout: 4px spacing scale, generous whitespace, subtle borders, restrained corner radii, responsive navigation.
